# SI Code Week 2026 · Desafio 02 · Torneio de Algoritmos

Este repositório é seu. Só você e a Coordenação conseguem ver.

| Arquivo | O que é |
|---|---|
| `despacho.py` | onde você escreve a função `despachar()` |
| `exemplos/log-antigo.txt` | um log real do sistema antigo, com a saída esperada em `log-antigo.saida.txt` |
| `tests/test_exemplos.py` | testes de exemplo |

## Rodar os testes de exemplo

```
python -m unittest
```

Python 3.12, só com a biblioteca padrão.

## Entregar

1. Faça commit (e push, se estiver no terminal).
2. Copie o endereço da página do commit, ou o SHA, e cole no formulário do Desafio 02, com a justificativa.

Vale o commit que você informar, não o que vier depois.
